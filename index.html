Калькулятор стоимости заказа

Выберите товар, укажите количество и нажмите кнопку «Рассчитать». Стоимость заказа будет рассчитана автоматически.

Введите целое положительное число, например 3.

Как пользоваться калькулятором

  1. Выберите товар из списка.
  2. Введите количество товара цифрами.
  3. Нажмите «Рассчитать стоимость».
  4. Итоговая сумма появится рядом с кнопкой.
